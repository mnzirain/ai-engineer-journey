## Overview

This project demonstrates an Enterprise Model Context Protocol (MCP) Server that enables Large Language Models (LLMs) to securely discover, describe, and invoke enterprise tools through a standardized protocol.

The architecture follows modern AI infrastructure patterns used across enterprise LLM platforms and agentic AI systems.
